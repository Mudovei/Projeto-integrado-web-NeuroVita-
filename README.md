# Projeto-integrado-web-NeuroVita-
PLataforma web online de nome NeuroVita, utilizada para automatizar os processos de cadastro a agenda de pacientes do instituto Vem Viver, assim como gerar prontuário eletrônico e laudos psicologicos

**Como executar o projeto:**

- Instalar o servidor local da aplicação
- Disponibilizar o Banco de Dados no servidor local
- O administrador criar os usuários
- Dispobilizar a url da aplicação na internet
- Dispobilizar o manual da aplicação
